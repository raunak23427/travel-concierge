## HOW THE AGENT RANKS THESE

find_nearby() filters on category, monsoon_safe, max_price_band and opening hours,
then scores each surviving row transparently:
    proximity = max(0, 1 - distance_km / 30)
    value     = 1 - price_band / 4
    score     = proximity * 0.75 + value * 0.25
The score is returned to the model so it can explain WHY something surfaced.
