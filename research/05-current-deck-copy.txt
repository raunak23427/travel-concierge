## Slide 9
- TOOL-CALLING AGENT & GROUNDING ARCHITECTURE.
- Agent Reasoning Loop
- Perceive
- guestMessage  ∪  schedulerTrigger
- → bookingContext
- get_booking_context
- Decide
- model selects tool tᵢ ∈ T, |T| = 7
- args ← schema(tᵢ)
- get_weather · find_nearby
- Act
- execute(tᵢ, args) → result
- result appended to context
- reschedule_day · notify_host
- loop until no tool call  ·  max 8 rounds
- Grounding — the model composes, it never invents
- Ranking
- proximity = max(0, 1 − d / 30)
- value = 1 − band / 4
- score = 0.75·proximity + 0.25·value
- Filters
- category · area · monsoon_safe
- max_price_band · open_at
- → 14-place tagged Goa dataset
- Proactive Scheduler
- pre_checkin — T−24h
- weather_reroute — advisory ∧ ¬safe
- checkout_prep — checkout day
- Every venue, price and distance in a reply traces to a tool result. No tool result → no claim.

**Speaker notes:** This is the slide the technical panel will interrogate. The ranking formula is real and returned to the model so it can explain why something surfaced.
