## PS1 — Trust & Discovery Layer for Local Rentals

**Problem statement:** Guests booking informal/local rentals (unlike hotel chains) have no reliable way to verify host legitimacy or judge neighbourhood fit before booking — leading to scams, mismatched expectations, and lost trust in local marketplaces.

**What they'd need to build:**

- Host verification module — ID/document upload + basic automated checks (face match, doc authenticity heuristics), producing a "Verified Host" badge
- Scam/fraud detector — a model or rule-engine trained on listing text/price/review patterns to flag likely fake or duplicate listings
- "Neighbourhood vibe" generator — pulls review text + (mock) local data (noise, distance to beach, nightlife density) and produces a short AI-written summary per listing ("quiet, 5 min to Baga beach, mostly families")
- Trust score UI — a badge/score shown on listing cards combining verification + review sentiment + scam-risk

**Tech angle:** NLP/sentiment on reviews, basic classifier for fraud signals, simple verification flow, clean listing-card UI.

**Judging hook:** directly pluggable into a real listing page — strong "could ship tomorrow" story.

## PS2 — AI Trip Concierge (post-booking agent) ← SELECTED

**Problem statement:** Booking platforms end their relationship with the guest at checkout — there's no continuity into the actual trip, which is where loyalty and upsell opportunity live.

**What they'd need to build:**

- Itinerary generator — given the booked property's location + dates, output a day-by-day plan (beaches, food, activities) using a mix of static Goa data + LLM generation
- Proactive notification agent — a scheduled job (cron-style) that messages the guest with context-aware nudges: weather-based plan changes, "your check-in is tomorrow, here's parking info," local event alerts
- Conversational interface — WhatsApp/Telegram bot where guests can ask "what's a good place for dinner near me tonight" and get a real answer
- Local recommendation dataset — even a scraped/curated JSON of restaurants, activities, transport options tagged by area

**Tech angle:** LLM agent + tool-calling, scheduling/cron, messaging integration, lightweight local knowledge base.

**Judging hook:** demoable live via a chat interface — very visual, good for a 5-min pitch.

## PS3 — Host Growth Toolkit

**Problem statement:** Individual/small hosts can't compete with big platforms' algorithmic pricing, professional photography, and marketing reach — most either underprice or get buried in search.

**What they'd need to build:**

- Dynamic pricing suggester — model/heuristic factoring in season, local events (festivals, monsoon), competitor listing prices, occupancy trends → suggests a nightly rate range
- Auto-listing generator — upload raw photos + basic property facts → AI writes the listing description, suggests title, flags weak photos ("this room needs better lighting")
- WhatsApp booking assistant for hosts — since many hosts won't use a dashboard, a bot that lets them manage bookings/availability entirely via WhatsApp messages
- Simple host dashboard — booking calendar, earnings summary, pricing suggestions in one view

**Tech angle:** basic pricing model/heuristics, image quality/description generation, messaging-bot backend, dashboard frontend.

**Judging hook:** strong marketing narrative ("Airbnb takes a cut and gives nothing back — we make hosts win") plus real technical depth.
